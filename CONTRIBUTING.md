# Contributing

Contributions use [GitHub Flow](docs/github-flow.md). Work from a short-lived
branch, open a pull request, and merge into `main` only after the required
checks and review pass.

Before starting product implementation, read [AGENTS.md](AGENTS.md), the
[product vision](docs/vision-y-requisitos.md), the [modeling methodology](docs/metodologia-modelado-sdd.md),
and the [agent toolchain contract](docs/agent-tooling.md). Product changes must
have an approved `Product baseline ready` and `Change ready` state.

Use the pull request template and report commands, versions, passed checks,
intentional skips, compatibility limits, and the distinction between technical
verification and product-owner validation.

Repository language is English for code, technical names, comments, commit
messages, and versioned technical documentation. The product itself must
support its approved multilingual requirements.
