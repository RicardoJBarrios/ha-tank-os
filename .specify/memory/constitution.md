# Spec Kit Constitution Status

**Status:** Not adopted.

This repository currently uses BMAD for product discovery and global
architecture, and OpenSpec for bounded changes. Spec Kit is installed only as
an optional compatibility adapter; this file is not an engineering authority
until the product owner explicitly adopts and ratifies a constitution.

When Spec Kit is adopted, this file MUST be replaced through a reviewed,
English-language repository change that records the approved principles,
version, ratification date, governance rules, and compatibility with the
existing BMAD and OpenSpec authorities.
